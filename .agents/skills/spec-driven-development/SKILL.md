---
name: spec-driven-development
description: Create, refine or execute DeepResearch Lite phase specifications with requirement-to-test traceability.
---

Read AGENTS.md and specs/architecture.md, then the active phase triplet. Resolve conflicting requirements before coding. Give each functional requirement a stable phase-prefixed ID. Link tasks to requirements and concrete acceptance tests; specify inputs, outputs, failures and dependency ownership. Preserve exclusions and centralized limits. Separate proposed decisions from verified capability. Mark tasks complete only with implementation and check evidence. For documentation-only work, leave application tasks unchecked.
